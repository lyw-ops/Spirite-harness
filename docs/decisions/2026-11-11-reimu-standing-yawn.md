## 设计

站着打一个哈欠：手从身侧抬到胸前、眼睛半闭（过渡姿态）→ 手捂住嘴、闭眼、眼角一滴泪（保持 1.2 秒）→ 手放下 → 回到站姿，共 2.3 秒。
用户说过待机就正常站着，所以哈欠不是自发的待机动作，只在下面三种时候出现，而且任何点击都能打断它：

| 触发 | 台词 |
| --- | --- |
| 站着没人理满 20 分钟后的第一下点击（「站着睡着了」） | 哈啊…嗯？ / 呼啊…有事？ / 嗯…睡着了 |
| 深夜和清晨（23 点到 7 点）点她，轮到时段那一句时 | 这么晚，妖怪出没 / 早…茶还没泡呢 |
| 深夜和清晨启动应用、她正站着时的问候 | 这么晚还不睡？ / 早，先泡壶茶 |

工作中（坐着吃饭）、喝茶时不打哈欠。「减弱动态」下只出台词，画面保持站姿。

## 作画与接收

工作目录 `build/reimu-standing-yawn-v1/`。以批准的站姿静帧（1254×1254，`4b390982…`）为底，一次调用画出两张关键帧，交付为透明底 RGBA、机位偏移 0 px。

和坐姿不同，这次有一条手臂离开了轮廓，原来袖子的位置要变成透明，所以接收脚本 `yawn_intake.py` 做了三处不同的处理：
差异按颜色**和**透明度一起量（袖子是白的，只按颜色量会漏掉）；贴回时用预乘像素混合，避免透明边缘发黑；不依赖 596 px 的旧工具。

图像模型把整张图重画得比批准图更锐利，轮廓在未改动的地方与批准图相差 1–3 px。第一次按给模型看的整框 (440,280)–(930,880) 取用，
左袖和左侧头发被带进了一部分重画的像素，裙边在框的下沿留下一道残影。改为按交付实测的两块矩形取用：
脸 (495,285)–(770,480) 和抬手一侧的半身 (556,440)–(945,1000)（旧袖子和手一直到 y 950，轮廓到 y 1000 重新吻合），
