# 2026-11-11 · 漫画对话框，已安装 1.21 / build 23

用户用了 1.20 之后说「对话可以做成漫画的那种对话框」，并贴了一张参考图：云朵形（带小圆圈）、爆炸形、椭圆带尾巴、硬边多边形，白底黑线。

## 做法

台词原来画在人物窗口里靠下的一条红色圆角条上。现在由 Consumer 的 `desktop/macos/SpeechBalloon.swift` 画在一个独立的、不接收鼠标的小窗口里，
人物窗口本身不再画任何文字。字体用系统自带的手写体 Hannotate SC（缺失时退回圆体、再退回系统粗体）。

| 形状 | 何时用 |
| --- | --- |
| 椭圆带尾巴 | 普通说话 |
| 爆炸形（上角三道强调线） | 生气，或台词里有「！」 |
| 云朵加三个小圆圈 | 半眼盯人，或台词里有「…」「——」 |
| 硬边多边形带小尖角 | 被拖动、出错、被中断 |

选择规则 `BalloonStyle.pick` 只看台词和当前节点；断行规则 `BalloonStyle.wrap` 对 6 个字以上的台词只在标点后断一次（断点处的逗号去掉），
没有合适的标点就不断，所以不会把词拆开。两条规则都在 `PetBehavior.swift` 里并有测试。

位置：默认在头顶偏右，尾巴指向角色**实际占据的矩形**（按当前画面的不透明范围量一次并缓存），所以坐着吃饭时尾巴也够得到她；
头顶放不下或会盖住任务状态框时换到脸旁，贴着屏幕边时朝向屏幕内侧，最后才放到下方。字号随桌宠大小从 12 pt 到 16 pt。

## 过程中改掉的两处

第一版审阅图上云朵的鼓包是按椭圆参数角均分的，两端挤成尖角、顶上又长又平，不像云；改为按轮廓弧长均分、每个鼓包用两个外推控制点，变成圆鼓包。
第一版的尾巴对准的是窗口顶边，坐姿的生气图离对话框很远；改为对准角色的不透明范围。审阅图：`build/reimu-manga-balloons-v1/balloons-v1.png`、`balloons-v2.png`
（由应用自身的 `--render-balloons` 输出，160 px 实际画面、明暗两种底色）。
