## 规则

| | |
| --- | --- |
| 入睡条件 | 时钟在 23 点到 7 点；观察到的状态是空闲、一轮刚结束或 Codex 没开（`idle` / `round_ended` / `disconnected`）；没有点击、拖动、喂食、状态变化满 20 分钟 |
| 入睡过程（4.8 秒） | 烟雾过渡到矮桌前 → 睁眼坐着 1 秒（台词「困了…睡会儿」等）→ 哈欠 1.2 秒 → 困倦 1.2 秒 → 闭眼、又抬一下头 → 睡着，冒 4 秒「Zzz…」 |
| 睡着 | 一直保持睡姿，画面不动，不再说话；计时器停下，只有每秒一次的心跳 |
| 点她 | 立刻醒：困倦 → 哈欠 → 睁眼（2.4 秒，台词「嗯…谁啊」「唔…赛钱呢？」「…再睡五分钟」）→ 烟雾过渡回站姿，20 分钟重新计 |
| 天亮（8 点起） | 同样的醒来过程，台词「呼啊…天亮了」 |
| Codex 开工、等确认、出错、状态待确认 | 立刻离开睡姿，不播醒来动作（开工直接是矮桌吃饭，不冒烟）；Codex 在夜里关掉不会吵醒她 |
| 拖动、喂饭团 | 立刻离开睡姿 |
| 暂停、系统休眠、菜单里关掉 | 立刻回站姿，之后不会入睡 |
| 减弱动态 | 仍然会睡（睡姿是状态不是动画），但跳过入睡和醒来的中间姿态，也没有烟雾 |
| 关掉台词 | 照睡，不出台词和 Zzz |
| 开关 | 右键菜单「深夜没人理就趴桌睡」，偏好键 `noNightSleep`，**默认开** |

两处是我自己定的，和早先的写法不同，需要用户知道：

- 设计记录里这一项写的是「默认关」。我改成了默认开：这是用户点名要做的功能，只在深夜、空闲满 20 分钟后出现，和白天自发吃饭、托腮（仍然默认关）不是一回事；默认关的话用户得先找到开关才看得到。
- 9 月的交接里写过「减弱动态冻结且不自动触发」。我改成了减弱动态下照样入睡、只是不播中间姿态，理由同「等确认时托腮」：换一个静止姿态不算动画。用户的减弱动态现在是开着的，按旧写法这个功能对用户等于不存在。

它和站姿哈欠的关系：深夜开着这个功能时，「站着没人理满 20 分钟后第一下点击会打哈欠」不再发生（那时她已经睡了，点击变成叫醒）；白天不受影响。
