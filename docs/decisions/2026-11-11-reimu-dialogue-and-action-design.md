用户要求：「由你来担任设计师，来给灵梦设计更多的动作和对话，参考灵梦的个人性格特色，以及其他桌宠的项目经验」。

## 1. 设计依据

**人设（只取这几条，每句台词、每个动作都要能对上其中一条）**

| 特征 | 用法 |
| --- | --- |
| 懒，能坐着不站着，最爱喝茶 | 开工嫌麻烦、收工先泡茶、久坐提醒说的是「喝口茶」而不是「加油」 |
| 香火钱永远不够，神社没人来 | 待机被点时招呼参拜、指赛钱箱；戳她要收钱 |
| 解决异变是份差事，报酬是一顿饭 | 工作 = 异变 / 委托；任务越多饭越好（Tier 越高越开心） |
| 嘴上不客气，直觉准 | 半眼盯人、「直觉说你很闲」、连点威胁退治 / 梦想封印 |
| 会飞 | 被拖着走时抗议「我自己会飞啦」 |
| 神社的四季：赏花、刨冰、扫落叶、被炉、新年参拜 | 待机被点时偶尔说一句当季的话 |

**其他桌宠项目的经验（dsh-pet、whale-musume、deepseek-pet 以及本项目自己踩过的）**

1. 陪伴感主要来自「事情发生时她说一句」，而不是点她才说话。此前灵梦只有被点击才有台词，开工、收工、等确认、出错全程沉默。
2. 点击要有阶梯，每一级都换表情，不只是换字。
3. 台词要轮换，同一句连续出现两次就显得是机器。
4. 自发的话必须有节制：常规事件设间隔，只有需要用户处理的事才一定说。
5. 动作从同一张基准姿态出发并回到它，角色比例和地面线不变；本项目站姿与坐姿比例不同（发行跨度 245 px 对 374–454 px），所以新动作优先做在「同一姿态族」内，不跨族。
6. 160 px 下嘴不可读（实测 3–6 px），动作必须靠手、道具、整体轮廓；可读下限是 160 px 下 250 px 的变化量。
7. 新姿态用图像模型改批准静帧的关键帧，只取量好的范围内的像素；脚本画的道具和重采样的比例都被否过，不再走这两条路。

## 2. 第一批：已实现并安装（不需要新图）

### 2.1 她会对真实的工作事件说一句

只在观察到的状态真的变化时触发，是叠在当前画面上的一句话：不启动动作、不重置循环相位、不动待机计时。
菜单新增「工作状态变化时说一句」，默认开；偏好键 `muteRemarks`。每句都写进行为日志（`kind: remark`）。

| 事件 | 条件 | 台词（按序轮换） |
| --- | --- | --- |
| 启动问候 | 每次启动一次，按时段 | 早，先泡壶茶 / 中午好，吃了吗 / 下午好，喝茶吗 / 晚上好，还忙啊 / 这么晚还不睡？；1 月 1–3 日：新年好！来参拜 |
| 开工 | 进入工作中；距上一句 ≥ 2 分钟 | 又有异变？麻烦 / 好吧，开工开工 / 委托来了，出发 / 早点解决早喝茶 |
| 任务变多 | 档位上升；同样的 2 分钟间隔 | 还加？饭要加量 / 委托越来越多了 / 忙不过来了啦；升到 5 档：大异变！全力上 |
| 任务变少 | 档位下降且仍在工作 | 少了一件，轻松 / 总算松口气 |
| 一轮结束 | 这一轮工作 ≥ 45 秒 | 这一轮收工了 / 告一段落，喝茶 / 收工，泡茶去 / 先歇会儿吧 |
| 等用户确认 | 每次都说 | 喂，等你确认呢 / 这个得你来定 / 你不点头我不动 |
| 出错 | 每次都说 | 啧，出岔子了 / 这次不太顺… / 直觉说得重来 |
| 被中断 | 从工作中被打断 | 欸？这就停了？ / 半路喊停啊… |
| 久坐 | 连续工作满 50 分钟（中途歇不到 5 分钟不算断） | 歇会儿喝口茶吧 / 坐太久会腰疼哦 / 茶都凉了，歇歇 |

「一轮结束」的台词刻意不说「解决了」：观察端只知道这一轮结束，不知道成没成功，状态卡片也是这样写的。

### 2.2 点击阶梯多一级，每个场景的台词加厚

单击「嗯？」→ 双击连眨眼 → **第三下半眼盯人（新）** → 第四下生气。
半眼盯人用的是已批准的站姿半睁眼图，停住一秒；她在吃饭时保持碗在画面里，只换台词。

时段句：早…茶还没泡呢 / 该吃午饭了吧 / 下午茶时间到 / 天黑了，早点歇 / 这么晚，妖怪出没。

第四下：むっ！再闹退治你 / 再闹就梦想封印；吃饭时：让我吃完嘛 / 吃饭都不安生。

每个场景各自轮换（原来共用一个计数器，换场景会跳句）。所有台词不超过 9 个字，测试逐句检查（含全部时段与季节）。

### 2.3 三个站姿小表情（只用已批准的三张眼皮图）

| 表情 | 何时 | 画面 |
| --- | --- | --- |
| 半眼盯人 | 第三下点击 | 半睁眼停 1 秒再睁开 |
| 闭眼呼气 | 一轮结束、回到站姿时 | 闭眼 0.7 秒，配「这一轮收工了」 |

## 3. 第二批：需要新图的动作（只有设计，未画）

按「人设贴合度 × 出现频率 ÷ 风险」排序。做法都是图像模型改批准静帧的关键帧，每个动作 1 张新基准 + 2 张关键帧起步。

| 顺序 | 动作 | 触发 | 人设依据 | 姿态族与做法 | 风险 |
| --- | --- | --- | --- | --- | --- |
| 1 | **收工茶**：双手捧茶杯，抬到嘴边闭眼喝一口，冒热气 | 一轮结束后的 30 秒（现在是直接切回站姿）；久坐提醒时 | 最像她的一件事 | 矮桌族。从 Tier3 批准图出发（桌上本来就有茶杯），撤掉碗筷改成捧杯；与工作吃饭同桌同比例，收工不再是坐→站的硬切 | 中：新基准要整幅重画一次，需过调色板和支撑线门 |
| 2 | **站姿打哈欠**：一只手抬到嘴边，闭眼 | 深夜待机被点；早晨问候 | 懒 | 站姿族。手在身体轮廓内移动，适用「框内取像素」 | 低–中：袖子宽，原位置会露出背景 |
| 3 | **举御币**：右手举起御币，皱眉 | 待机第四下（现在会切到坐着拿饭团的生气图，场景对不上）；开工 | 退治 | 站姿族。御币伸出轮廓外，需要品红底色抠图 | 高：透明背景是 9 月失败过的环节 |
| 4 | **垂头叹气** | 出错 | 嘴硬但会泄气 | 站姿族，轮廓内变化 | 低 |
| 5 | **飘起来**：双脚离地、裙摆和袖子飘动 | 拖动 | 会飞 | 站姿族，整体轮廓变化，需要底色抠图 | 高 |
| 6 | **扫地**：竹扫帚左右两拍 | 待机自发（默认关，随「待机时偶尔…」开关）；秋季更常见 | 神社日常 | 站姿族 + 新道具 | 高：道具必须是真画的，脚本画的被否过 |
| 7 | **夜里伏桌睡**：入睡 / 睡 / 醒三段接力 | 深夜长时间待机（默认关） | 懒 | 已有 9 月选定的睡姿和四张预览姿态，需要正式化 | 中：睡眠调度此前刻意没做 |

不需要新图、但我这轮没做的一项：**等确认时改用已批准的托腮图**（现在是静止站姿，和待机分不出来）。
它会改变一个状态的默认画面，而且近两个月真实只触发过一次，所以留到用户点头再做。

## 5. 边界

- 台词和三个小表情都没有经过用户逐句、逐个确认；视觉门是 `in_review`。
- 没有在屏幕上看过实际播放。安装时用户偏好「减弱动态」仍为开启（`reduced = 1`），所以三个小表情目前在屏幕上不会动，只有文字会出现；本轮没有改这个设置。
- 事件台词默认开启是我的设计决定，不是用户指定的；它只跟随真实事件，待机时仍然只是站着，没有新增任何自发的待机行为。
- 第二批一张图都没有画。画图要调用本机 Codex 的图像生成（占用户的额度、把批准图发给 OpenAI），需要用户对这一批点头。
