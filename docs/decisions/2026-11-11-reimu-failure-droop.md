## 设计

观察到的工作状态变成「出错」时，她垂一次头、叹一口气，然后重新站好（嘴硬但会泄气）：
头前倾下沉、眼睛半闭看地面（0.3 秒）→ 头垂得更低、闭眼、张嘴呼气、嘴边一小团气、蝴蝶结耷拉下来（1.6 秒）→ 抬头（0.4 秒）→ 回到站姿，共 2.5 秒。

| | |
| --- | --- |
| 触发 | 状态从别的状态变为 `failed` 的那一刻，每次出错只播一遍；拖动、点击都不会让它重播 |
| 台词 | 不变：「啧，出岔子了」「这次不太顺…」「直觉说得重来」；关掉台词时动作照播 |
| 之后 | 出错状态持续期间保持原来的站姿，不一直垂着头 |
| 减弱动态 | 不播，保持站姿加台词（与现在相同） |
| 缺素材 | 保留现在的眼皮皱一下 |
| 烟雾过渡 | 不出现（出错一向是直接切换） |

它不是 `PetAction`（出错状态下本来就不允许开始任何动作），而是 `presentation(droopAllowed:)` 里按「进入出错的时刻」选帧：
`PetBehavior.droopPlan`、`droopDuration = 2.5`、`droopStarted`。`PoseFamily(.droop)` 属于站姿族。
