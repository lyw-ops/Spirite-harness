我说设计里唯一没做的是「画出来的坐下和站起」，用户回复「做」。前面各节写的是候选阶段的状态；用户确认和安装见文末「用户确认与安装」。

## 做的是什么，不是什么

9 月冻结的 `2026-09-20-reimu-work-transitions-spec.md` 要求的是：从站姿的原样逐帧画到坐姿第一帧的原样，两端逐像素相等，6–9 帧，每条路线单独成包。
这一条做不到，原因没有变：站姿和各张坐姿不是同一个比例（坐姿里人物大得多，还带桌子和榻榻米），两端之间必然有一次放大，
而规格明确不允许用整体缩放充当角色动作。9 月为此试过三次都失败了。

这次做的是另一件事：**在站姿的比例下，把「往下坐」这段身体动作真的画出来**，只让烟雾盖住最后那一下比例切换。

- 离开站姿（去矮桌或坐到地上）：屈膝下沉 → 跪坐在地 → 起烟 → 满云下换成坐姿画面 → 烟散。
- 回到站姿：起烟 → 满云下换成跪坐 → 烟散 → 起身 → 站好。

所以它是显示桥的加强，仍然如实归在显示桥里：`REIMU-WORK-TRANSITIONS-001` 的作者帧路线没有因此关闭任何门，规格里的 30 条路线仍然是空的。

## 时序

| | 步骤（每步 80 毫秒） | 总长 | 画面换成新姿势的时刻 |
| --- | --- | --- | --- |
| 原来（纯烟雾） | 旧 + 起烟 → 旧 + 满云 → 新 + 满云 → 新 + 散开 → 新 + 余烟 | 0.40 秒 | 0.16 秒 |
| 坐下 | 屈膝 ×2 → 跪坐 ×2 → 跪坐 + 起烟 → 跪坐 + 满云 → 新 + 满云 → 新 + 散开 → 新 + 余烟 | 0.72 秒 | 0.48 秒 |
| 站起 | 旧 + 起烟 → 旧 + 满云 → 跪坐 + 满云 → 跪坐 + 散开 → 跪坐 + 余烟 → 跪坐 → 屈膝 ×2 | 0.64 秒 | 0.16 秒（之后 0.48 秒是起身） |

- 行为模型照常立刻切换，状态、台词、对话框都不等；只有画面晚。坐下时坐姿画面比原来晚出现 0.32 秒。
- 桥进行到一半时如果来了点击反应、拖动或出错，桥立刻撤掉（原来的纯烟雾桥在前 0.16 秒里不会撤，这次一并改了）。
- 地上坐和矮桌之间（两边比例也不同，但都不是站姿）仍然只有烟雾。
- 「减弱动态」、暂停、菜单里关掉「换姿势时冒一团烟」时都不出现；缺素材时退回纯烟雾。没有新增开关。
