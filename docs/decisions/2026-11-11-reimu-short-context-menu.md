| 工作状态（灰字一行） | 例如「工作状态待确认」；有素材不可用时多一行「有 N 项素材不可用（见「更多」）」 |
| 喂一口饭团 | 不变 |
| 暂停动画 / 继续播放 | 不变 |

| 大小和位置 ▸ | 160 / 240 / 320 / 400 px；回到右下角 |

| 退出灵梦桌宠 | 不变 |

顺带补上了此前缺的提示：御币、飘浮、扫地、坐下站起、睡姿、烟雾素材损坏时，「更多」里各有一行说明（原来只有前几个资源包有）。
